HAVE QUESTIONS?

Frequently Asked Questions

Some useful information about our website creation process.

What types of websites can PUNITRO create?
We can work on static websites for shops, schools, small businesses, personal portfolios and service providers.
Will my website work on mobile phones?
We design responsive layouts so website content can adapt to different screen sizes. Testing is important before publishing.
Can customers contact my business through WhatsApp?
Yes. A WhatsApp link can open a conversation with your business when the correct phone number is configured.
Can I update my website later?
Yes. Website text, images and other content can be edited. The updated files must then be published again.
Can you help publish my website online?
We can help with publishing suitable static websites using services such as GitHub Pages.
